## Getting Started

Visual Studio Code is a lightweight editor with a rich extension ecosystem. Use it for fast iteration, debugging, and source control.

---

## Recommended extensions

- **Pitch Black Modern** by Yash-pluto for a sleek dark theme
- **ESLint** for linting JavaScript and TypeScript
- **Prettier** for automatic formatting
- **GitLens** for git history and blame

---

## Workspace settings

Use `.vscode/settings.json` to keep editor settings consistent across your team.

```json
{
  "editor.tabSize": 2,
  "editor.formatOnSave": true,
  "files.trimTrailingWhitespace": true
}
```

---

## Productivity tips

- use `Ctrl+P` to quickly open files
- use `Ctrl+Shift+P` to access commands
- use the integrated terminal for shell tasks

---

## Debugging

Use launch configurations and breakpoints to debug Node.js or browser code directly from the editor.
