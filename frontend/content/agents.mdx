## Getting Started

Agents automate multi-step tasks by combining planning, tool use, and decision making. They can orchestrate actions across APIs, data sources, and interfaces.

---

## Core concepts

- **tools**: capabilities the agent can call
- **planner**: chooses the next step
- **executor**: performs actions and evaluates results

---

## Example flow

1. receive a goal
2. search for relevant information
3. call tools to gather data or perform actions
4. decide the next step

---

## Use cases

- workflow automation
- research assistants
- code generation with validation

---

## Safety

Control what tools an agent can access, validate outputs, and ensure actions remain within authorized boundaries.
