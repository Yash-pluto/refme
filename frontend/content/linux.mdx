## Getting Started with Linux

Linux is a free, open-source operating system that powers everything from personal desktops to enterprise servers and cloud infrastructure. It's essential for modern software development, DevOps, and system administration. The command line (shell) is the primary interface for interacting with Linux, offering power and flexibility that graphical interfaces cannot match.

### Why Linux?

Linux provides:
- **Stability**: Runs for years without requiring a restart
- **Security**: Multi-user, multi-task architecture with robust permission systems
- **Flexibility**: Customize everything from the kernel to user applications
- **Cost**: Free and open-source, no licensing fees
- **Community**: Massive community support and extensive documentation

### Linux Distributions

Popular distributions include:
- **Ubuntu**: Beginner-friendly, extensive support, widely used
- **CentOS/RHEL**: Enterprise-focused, long-term support
- **Debian**: Stable, minimal, perfect for servers
- **Fedora**: Cutting-edge features, good for development
- **Alpine**: Lightweight, ideal for containers
- **Arch Linux**: Minimalist, rolling release, for advanced users

## Understanding the File System

### Filesystem Hierarchy

Linux follows the Filesystem Hierarchy Standard (FHS). Key directories include:

```
/               # Root directory
/bin            # Essential user binaries (ls, cp, mv)
/sbin           # System binaries (for root/admin use)
/lib            # Shared libraries needed by binaries
/etc            # Configuration files
/home           # User home directories
/root           # Root user's home directory
/tmp            # Temporary files
/var            # Variable data (logs, caches, databases)
/opt            # Optional packages
/usr            # User programs and data
/proc           # Process information (virtual filesystem)
/sys            # System information (virtual filesystem)
/dev            # Device files
/boot           # Boot files and kernel
/srv            # Service data
/mnt            # Mount points for temporary mounts
```

## File Permissions and Ownership

### Understanding Permissions

Permissions use a three-layer model: Owner (User) | Group | Others. Each layer has three permissions: Read (r/4), Write (w/2), Execute (x/1).

```bash
# View permissions
ls -l

# Example output:
# -rw-r--r-- 1 user group 1024 Jan 1 12:00 file.txt
# [permissions] [links] [owner] [group] [size] [date] [name]

# Permissions breakdown:
# -        rw-        r--        r--
# type     owner      group      others
# -=file   r=read     r=read     r=read
# d=dir    w=write    -=none     -=none
# l=link   x=execute  x=execute  x=execute
```

### Changing Permissions

```bash
# Symbolic notation (easier to read)
chmod u+x script.sh            # Add execute for owner
chmod g+r file.txt             # Add read for group
chmod o-w file.txt             # Remove write from others
chmod u=rwx,g=rx,o= file.txt   # Set specific permissions
chmod a+x script.sh            # Add execute for all

# Numeric notation (octal)
chmod 755 script.sh            # rwxr-xr-x
chmod 644 file.txt             # rw-r--r--
chmod 700 secure_dir           # rwx------
chmod 600 private_file         # rw-------

# Recursive changes
chmod -R 755 directory/
chmod -R u+w directory/
```

### Changing Ownership

```bash
# Change owner
chown user file.txt
chown user:group file.txt      # Change owner and group

# Change group only
chgrp group file.txt

# Recursive changes (must be root)
sudo chown -R user:group directory/

# Common ownership patterns
sudo chown root:root /etc/config.conf
sudo chown www-data:www-data /var/www/html
```

### Special Permissions

```bash
# Set User ID (SUID) - run as owner
chmod u+s script.sh            # Numeric: 4755
ls -l script.sh                # Shows 's' in owner execute position

# Set Group ID (SGID) - run as group
chmod g+s directory/           # Numeric: 2755

# Sticky bit - only owner can delete
chmod o+t /tmp                 # Numeric: 1777
ls -ld /tmp                    # Shows 't' in others execute position
```

```bash
sudo apt update
```

## Process Management

### Viewing Processes

```bash
# Process list
ps                             # Current shell processes
ps aux                         # All processes (BSD format)
ps -ef                         # All processes (UNIX format)
ps -eo pid,user,%cpu,%mem,command  # Custom columns

# Real-time process viewer
top                            # Interactive process viewer
htop                           # Enhanced top (requires install)
atop                           # Advanced system monitor

# Find specific process
ps aux | grep process_name
pgrep process_name             # Get PID directly
pgrep -l process_name          # Get PID and name

# Show process tree
ps aux --forest
pstree
pstree -p                      # Include PIDs
```

### Controlling Processes

```bash
# Terminate processes
kill PID                       # Send SIGTERM (graceful)
kill -9 PID                    # Send SIGKILL (force)
kill -SIGTERM PID              # Named signal
kill -SIGSTOP PID              # Pause process
kill -SIGCONT PID              # Resume process

# Kill by name
killall process_name
killall -9 process_name        # Force kill

# Kill multiple processes
pkill -f "command pattern"
killall -9 process_name process2

# Send signals
kill -l                        # List all signals
# Common signals:
# SIGTERM (15) - Graceful termination
# SIGKILL (9)  - Forced termination
# SIGSTOP (19) - Pause
# SIGCONT (18) - Resume
# SIGHUP (1)   - Reload config
# SIGUSR1 (10) - Custom signal
```

### Background and Foreground

```bash
# Run in background
command &

# Run in background, immune to logout
nohup command &

# Suspend current process
Ctrl+Z

# List suspended/background jobs
jobs
jobs -l                       # With PIDs

# Bring to foreground
fg
fg %1                         # Bring job 1 to foreground

# Continue in background
bg
bg %1

# Disown job (survive shell exit)
disown %1
disown -a                     # All jobs
```

## User and Group Management

### User Management

```bash
# Add user
sudo useradd username
sudo useradd -m -s /bin/bash username  # With home and shell
sudo useradd -m -s /bin/bash -G sudo username  # With sudo access

# Create user with password
sudo useradd -m -p $(openssl passwd -1 password) username

# Modify user
sudo usermod -l newname oldname        # Rename
sudo usermod -s /bin/bash username     # Change shell
sudo usermod -aG sudo username         # Add to group
sudo usermod -G group1,group2 username # Set groups
sudo usermod -d /new/home username     # Change home

# Delete user
sudo userdel username
sudo userdel -r username               # Remove home and mail

# View users
cat /etc/passwd
getent passwd
id                             # Current user
id username                    # Specific user
whoami                         # Current user name
```

### Group Management

```bash
# Create group
sudo groupadd groupname

# Add user to group
sudo usermod -aG groupname username

# Remove user from group
sudo delgroup username groupname
sudo gpasswd -d username groupname

# List groups
cat /etc/group
groups                         # Current user's groups
groups username                # Specific user's groups

# Change group
sudo groupmod -n newname oldname

# Delete group
sudo groupdel groupname
```

### Sudo Configuration

```bash
# Edit sudoers file (safe method)
sudo visudo

# Common sudoers configurations
# Allow user to run all commands without password:

# Allow user to run specific command without password:

# Allow group to run commands:

# Check sudoers syntax without editing
sudo visudo -c

# View current sudo rules
```


## Security Best Practices

### File and Directory Security

```bash
# Secure permissions for files
chmod 600 ~/.ssh/id_rsa        # SSH private keys
chmod 644 ~/.ssh/authorized_keys
chmod 700 ~/.ssh               # SSH directory

# Secure home directory
chmod 700 ~                    # Owner only

# Secure config files
chmod 600 /etc/shadow          # Password hashes
chmod 644 /etc/passwd          # Public user info
```

### SSH Key Management

```bash
# Generate SSH key
ssh-keygen -t rsa -b 4096
ssh-keygen -t ed25519          # Modern, smaller, faster

# Copy public key to server
ssh-copy-id -i ~/.ssh/id_rsa.pub user@host
cat ~/.ssh/id_rsa.pub | ssh user@host 'cat >> .ssh/authorized_keys'

# SSH configuration
cat ~/.ssh/config
# Host myserver
#     HostName 192.168.1.100
#     User username
#     IdentityFile ~/.ssh/id_rsa
#     Port 22

# SSH with specific key
ssh -i ~/.ssh/key.pem user@host
```

### Firewall Management

```bash
# UFW (Uncomplicated Firewall - Ubuntu/Debian)
sudo ufw enable
sudo ufw allow 22/tcp          # Allow SSH
sudo ufw allow 80/tcp          # Allow HTTP
sudo ufw allow 443/tcp         # Allow HTTPS
sudo ufw deny 8080/tcp         # Deny port
sudo ufw status                # Show rules
sudo ufw reset                 # Reset to defaults

# Firewalld (RedHat/CentOS/Fedora)
sudo firewall-cmd --state
sudo firewall-cmd --add-port=22/tcp --permanent
sudo firewall-cmd --add-service=http --permanent
sudo firewall-cmd --reload
```

## Scripting and Automation

### Basic Shell Scripting

```bash
#!/bin/bash

# Variables
NAME="value"
NAME=${1:-default}             # Parameter with default

# Conditionals
if [ -f /path/to/file ]; then
    echo "File exists"
elif [ -d /path/to/dir ]; then
    echo "Directory exists"
else
    echo "Not found"
fi

# Loops
for i in {1..10}; do
    echo "Number: $i"
done

for file in *.txt; do
    echo "Processing $file"
done

while [ $count -lt 10 ]; do
    echo $count
    ((count++))
done

# Functions
function greet() {
    echo "Hello, $1"
}

# Execute and capture output
output=$(command)
output=`command`                # Older syntax

# Exit codes
exit 0                         # Success
exit 1                         # Error

# Check exit code
if command; then
    echo "Success"
fi

# Combine commands
command1 && command2           # Run if first succeeds
command1 || command2           # Run if first fails
```

### Cron Jobs

```bash
# Edit crontab
crontab -e

# List cron jobs
crontab -l

# Cron syntax
# Minute Hour Day Month DayOfWeek Command
# 0      0    *   *     *          /path/to/script.sh

# Examples
0 0 * * * /home/user/backup.sh                # Daily at midnight
0 */4 * * * /usr/bin/update_cache             # Every 4 hours
0 9 * * 1-5 /home/user/work_task.sh           # Weekdays at 9 AM
*/15 * * * * /home/user/frequent_task.sh      # Every 15 minutes
0 2 1 * * /home/user/monthly_task.sh          # First day of month

# Remove all cron jobs
crontab -r

# System-wide cron
sudo nano /etc/crontab
sudo run-parts /etc/cron.daily                # Run daily jobs manually
```

## Conclusion

Linux mastery comes from consistent practice with the command line. Start with basic file operations, progress to system administration, and eventually automate complex tasks with shell scripts. Join the vibrant Linux community, read man pages (`man command`), and always prioritize security and system stability.

Key takeaways:
- Master file permissions and ownership for security
- Use the package manager appropriate for your distribution
- Monitor processes and system resources regularly
- Automate repetitive tasks with scripts and cron jobs
- Keep systems updated and secure
- Practice safely in test environments first
