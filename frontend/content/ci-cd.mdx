## Getting Started

CI/CD automates the process of building, testing, and deploying software. Continuous integration catches problems early, while continuous delivery makes releases repeatable.

---

## CI pipeline

A CI pipeline typically includes:

- install dependencies
- run tests
- run linting
- build artifacts

---

## CD pipeline

Delivery pipelines deploy code to staging or production after passing CI checks. This can be automated or gated by approvals.

---

## Benefits

- faster feedback
- fewer manual errors
- consistent releases

---

## Best practices

- keep pipelines fast
- version your build configuration
- fail fast on broken code
