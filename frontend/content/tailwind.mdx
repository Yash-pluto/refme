## Getting Started

Tailwind CSS is a utility-first framework that provides low-level classes for styling directly in HTML or JSX.

### Installation

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

### Basic Configuration

```js
// tailwind.config.js
module.exports = {
  content: ["./app/**/*.{js,ts,jsx,tsx}", "./components/**/*.{js,ts,jsx,tsx}"],
  theme: {
    extend: {},
  },
  plugins: [],
};
```

---

## Utility Classes

Tailwind composes styling from single-purpose classes.

```html
<button class="px-4 py-2 bg-blue-600 text-white rounded-md hover:bg-blue-700">
  Click me
</button>
```

### Responsive classes

```html
<div class="grid gap-4 sm:grid-cols-2 lg:grid-cols-4">
  <div class="p-4 bg-slate-100">Item</div>
</div>
```

---

## Layout

Use utilities for spacing, sizing, and layout.

```html
<div class="flex items-center justify-between gap-4 p-6">
  <div class="flex-1">Content</div>
  <button class="rounded bg-green-500 px-4 py-2 text-white">Save</button>
</div>
```

### Grid & flex

```html
<div class="flex flex-col gap-4 md:flex-row">
  <div class="flex-1 bg-white p-4 shadow">Card</div>
  <div class="w-full md:w-1/3 bg-white p-4 shadow">Sidebar</div>
</div>
```

---

## Theming & Customization

Tailwind supports custom theme values in `tailwind.config.js`.

```js
module.exports = {
  theme: {
    extend: {
      colors: {
        brand: {
          500: "#2563eb",
          600: "#1d4ed8",
        },
      },
    },
  },
};
```

---

## Plugins & Best Practices

Tailwind plugins add utilities and components, while `@apply` lets you compose reusable classes in CSS.

```css
.btn {
  @apply inline-flex items-center justify-center rounded-md bg-blue-600 px-4 py-2 text-white;
}
```

Use semantic class naming only when it improves readability and keep most styling in utility classes for consistency.
