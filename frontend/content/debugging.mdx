## Getting Started

Debugging is the process of understanding why code behaves unexpectedly. Good debugging saves time and reduces repeated failures.

---

## Reproduce the issue

Narrow the problem to a minimal case. Reproducing the issue reliably is the first step to fixing it.

---

## Use tools

Use debuggers, console logs, and breakpoints to inspect state and control flow.

---

## Hypothesize and test

Make a small, verifiable hypothesis about the cause, then change one thing at a time.

---

## Common sources

- incorrect assumptions about data shape
- race conditions
- off-by-one errors
- missing error handling
