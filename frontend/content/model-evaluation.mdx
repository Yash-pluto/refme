## Getting Started

Model evaluation measures how well a model performs on the tasks it was trained to do. Use held-out data and relevant metrics to judge quality.

---

## Common metrics

- accuracy for classification
- precision and recall for imbalanced classes
- mean squared error for regression
- BLEU/ROUGE for language generation

---

## Validation

Use separate training, validation, and test sets. Avoid evaluating on the same data used for training.

---

## Overfitting

A model overfits when it performs well on training data but poorly on new data. Use regularization, simpler models, or more data.

---

## Comparison

Compare models using consistent datasets and metrics. Look beyond a single number and consider speed, robustness, and fairness.
