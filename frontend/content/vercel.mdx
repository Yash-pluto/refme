## Getting Started

Vercel is a platform for deploying frontend applications with minimal configuration. It supports frameworks like Next.js and static sites.

---

## Deploying

Connect your Git repository and deploy automatically on every push.

---

## Previews

Every pull request gets a preview URL so your team can review changes before merging.

---

## Serverless functions

Vercel supports serverless functions for backend logic alongside your frontend.

---

## Edge runtime

Use edge functions for low-latency server-side logic near users.
